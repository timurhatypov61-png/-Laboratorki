## Описание работы
В ходе лабораторной работы были освоены методы разбиения текста на чанки и сравнение метрик расстояний для векторного поиска. Проведен анализ готовых чанков и их длин. Реализованы три стратегии разбиения текста (без перекрытия, с перекрытием и по предложениям) и выбрана наиболее подходящая. Рассчитаны четыре метрики расстояний (Cosine, Euclidean, Cityblock, Dot Product) для поиска ближайших соседей, выявлены их сходства и различия. Применена L2-нормализация векторов, математически доказана эквивалентность косинусного и евклидова расстояний на нормализованных данных. Реализован алгоритм поиска по чанкам с оценкой качества (Hit Rate).

## Инструкция по запуску
1. Установите необходимые зависимости: `pip install -r requirements.txt`
2. Откройте файл `notebook.ipynb` в Jupyter Notebook или Google Colab.
3. Выполните все ячейки ноутбука сверху вниз.
