## Тема

Прикладные задачи на данных интернет-магазина

## Инструменты

- Python
- NumPy
- Pandas
- Matplotlib
- Jupyter Notebook

## Содержание

В работе выполнено:

- генерация DataFrame на 3000 заказов с 14 полями;
- первичный анализ данных и проверка структуры;
- подготовка данных: работа с датами, расчёт выручки и прибыли, 
  заполнение пропусков, создание возрастных групп;
- фильтрация по одному и нескольким условиям, поиск экстремумов;
- группировка данных по категориям, городам, VIP-статусу;
- визуализация: 9 графиков (гистограммы, столбчатые диаграммы, 
  линейный график);
- мини-анализ с выводами по 5 направлениям;
- итоговый аналитический вывод.

## Ключевые результаты

- 3000 заказов, общая выручка 179.5 млн рублей.
- Средняя выручка заказа: ~60 тыс. рублей.
- Лидер по выручке — категория «Спорт», минимум — «Одежда».
- VIP-клиенты дают ~14% выручки.
- Чем больше скидка, тем ниже средняя выручка заказа.
- ~80% заказов доставлены.
