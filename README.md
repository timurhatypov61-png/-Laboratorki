## Тема
Проверка статистических гипотез, анализ нормальности распределения данных и исследование гендерных различий с помощью Т-теста.

- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy (модуль stats)
- Jupyter Notebook

## Содержание работы

В работе выполнены две части:

### Часть 1. Гипотезы (Пренатальная диагностика)
- Загрузка данных новорождённых.
- Подсчёт количества мальчиков и девочек.
- Расчёт ИМТ (индекса массы тела).
- Получение описательных статистик (минимум, максимум, размах, среднее, медиана).
- Проверка всех показателей на нормальность (визуально через гистограммы, через асимметрию/эксцесс и через критерий нормальности Д'Агостино).
- Исследование гендерных различий по росту, весу и ИМТ с помощью Т-теста (с предварительной проверкой дисперсий по тесту Левена).

### Часть 2. Т-тесты (Психология)
- Загрузка данных психологического тестирования.
- Формулировка нулевой (H0) и альтернативной (H1) гипотез.
- Автоматизированный выбор правильного Т-теста для 15 психологических показателей.
- Расчёт статистики t и p-значения для каждого показателя.
- Определение показателей с наиболее сильными и наиболее слабыми гендерными различиями.

## Ключевые результаты

### По пренатальной диагностике:
- В выборке представлено 577 мальчиков и 473 девочек.
- Критерий нормальности показал p-value = 0.0000 для всех показателей (из-за большой выборки), однако распределения визуально близки к нормальным, что позволяет использовать Т-тест.
- **Гендерные различия статистически значимы (p < 0.05) по всем трём показателям:**
  - Рост: мальчики в среднем выше (52.00 см против 51.33 см).
  - Вес: мальчики тяжелее (3497 г против 3360 г).
  - ИМТ: у мальчиков чуть выше (12.91 против 12.74).

### По психологии:
- Из 15 психологических показателей статистически значимые различия между юношами и девушками обнаружены **только в одном** — «экстраверсия-интроверсия» (p-value = 0.00127).
- Наиболее слабые различия (фактически их отсутствие) — в показателе «средний IQ» (p-value = 0.869).
