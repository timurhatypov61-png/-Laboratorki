## Содержание работы

В работе выполнены следующие этапы:

1. **Аналитика и постановка задачи:**
   - Формулировка SMART-цели для снижения оттока клиентов.
   - Построение MECE-дерева декомпозиции причин оттока.
   - Определение типов систематических смещений выборки (survivorship, selection, recall).

2. **Первичный анализ данных:**
   - Классификация признаков на числовые, номинальные и порядковые.
   - Поиск выбросов с помощью правила трёх сигм (Z-score).

3. **Масштабирование (Scaling):**
   - Сравнение `MinMaxScaler`, `StandardScaler` и `RobustScaler` на данных с экстремальным выбросом.
   - Обоснование выбора конкретного скейлера для каждого числового признака.

4. **Кодирование категориальных признаков:**
   - `LabelEncoder` и `OneHotEncoder` для бинарного признака (Gender).
   - `OrdinalEncoder` с явным заданием порядка для признака (Education).
   - Frequency-кодирование для признака (City).

5. **Сборка препроцессинга:**
   - Объединение всех трансформеров в единый `ColumnTransformer`.
   - Разделение данных на Train/Test **до** применения масштабирования (защита от утечки данных).

6. **Работа с выборками:**
   - Реализация простой случайной и стратифицированной выборки.
   - Исследование влияния размера выборки на точность оценки медианы (закон больших чисел).

## Ключевые результаты

- **Выбросы:** В столбце `Income` обнаружен выброс (5 000 000 руб.). Для его корректной обработки выбран `RobustScaler`, так как он использует медиану и IQR и не чувствителен к экстремальным значениям.
- **Кодирование:** Для линейных моделей применен One-Hot (чтобы избежать ложного ранжирования), для образования — Ordinal (с сохранением иерархии), для городов — Frequency (чтобы избежать взрыва размерности).
- **Data Leakage:** Применение `fit_transform` только на Train-выборке и `transform` на Test-выборке предотвратило утечку данных. Количество признаков после препроцессинга увеличилось с 7 до 11.
- **Стратификация:** Показано, что стратифицированная выборка сохраняет баланс классов (30% ушедших), в отличие от простой случайной.
- **Закон больших чисел:** Доказано, что с ростом размера выборки (от 20 до 500) стандартное отклонение медианы дохода резко падает, стабилизируясь вокруг истинного значения.
