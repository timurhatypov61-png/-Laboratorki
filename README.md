## Описание работы
В ходе работы был выполнен полный цикл предобработки текстового корпуса (25 отзывов о фильмах). Реализована очистка текста от шума с помощью регулярных выражений и лемматизация с использованием библиотеки `pymorphy3`. Построены модели Bag of Words (униграммы и биграммы) с применением фильтров `min_df` и `max_df`. Рассчитана матрица TF-IDF, выделены ключевые слова и проведено сравнение с вариантом без стоп-слов. Выполнен разведочный анализ: частоты слов, длины документов и матрица косинусного сходства для поиска похожих отзывов.

## Инструкция по запуску
1. Установите необходимые зависимости: `pip install -r requirements.txt`
2. Откройте файл `notebook.ipynb` в Jupyter Notebook или Google Colab.
3. Выполните все ячейки ноутбука сверху вниз.
